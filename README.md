practica de clase

#Primera versio
Aquest projecte consisteix en una aplicació desenvolupada en Java dissenyada per gestionar les operacions pròpies d'un entorn de cinema o una plataforma de reproducció de continguts. L'estructura actual estableix les bases per controlar tant la part comercial com la part tècnica de la visualització.
Àmbits del Projecte

    Venda i Validació: El sistema inclou lògica per al càlcul de preus d'entrades, aplicació de promocions i validació de perfils d'usuari (com ara l'estudiantat).
    Catàleg i Espais: Permet l'organització del contingut audiovisual (pel·lícules) i dels espais on es reprodueixen (sales i sessions).
    Atenció al Client: Compta amb un apartat dedicat a la gestió de socis i serveis per a la comunitat d'usuaris.
    Reproducció Multidispositiu: El projecte està preparat per gestionar la visualització de contingut tant en entorns físics (projectors de cinema) com en entorns digitals (dispositius mòbils).
Aquesta és la primera versió del projecte, on s'ha definit l'arquitectura de classes i les relacions bàsiques entre els components del sistema per garantir una base escalable i orientada a objectes.
